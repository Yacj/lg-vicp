## 修复的共性原因

| 根因 | 修复与边界 |
| --- | --- |
| 基层厚度和板厚被全文数字校验混淆 | 按已验证字段角色及证据位置检查；混有基层材料的未明厚度由独立窄语义复核归属。主提案与备用Parser在实际执行入口共用校核，基层“200厚”不再误作板厚；原数值、比较符、来源、其他板厚及否定仍完整校验。 |
| 澄清回复、连续查询与实际执行采用不同条件 | 后端保存原始查询及新增条件，保留指标、比较符、数值、名称、来源；NEW 标签不单独清除有效任务。明确换话题、取消、修改和删除仍生效。 |
| 自动检索命中的来源反过来变成用户指定限制 | requestQuery 保存用户有效条件，query 保存本次实际原页绑定范围。自动获取的 documentIds 不自动升级为用户限制，显式来源限制保持。 |
| 模型重复填写读取字段、查询基准、介绍改写等标签导致合同互斥 | 对没有新增筛选的读取投影作无损归一；比较、解释及建议接受相应读取字段。清除空查询前重验原提案条件覆盖，不消除真实新条件。 |
| 产品咨询与参数/参考做法之间缺少连续范围 | 从实际已验证、同归属同项目且有效期内的产品上下文继承名称和参数焦点；介绍/建议插话不重置。只读取参数的目标可作一次窄范围复核，不生成工程数值或正式身份。 |
| 待澄清 R 的口径仍交给模型重猜 | 在有效待查任务中，仅完整补充一个封闭 R 指标名时，后端保留原数值并询问产品、材料层或整构造口径。包含选择、换题等其他文字时仍执行正常语义与授权校验。 |
| 目标识别与候选身份、置信度相互覆盖 | solutionOperation 只表达动作；引用 Parser 仅理解称呼，Backend 从真实授权池、实际阅读焦点、来源和 Revision 唯一绑定。引用层不能改写操作、置信度或范围；没有模型自动 Confirm。 |
| 已读正式行缺少层次，核对参数和报告信息不连续 | 只读取同一发布构造/版本、规格范围和来源内的真实层次，读取和 Confirm 再核验；报告只消费冻结层次。没有从其他构造拼接参数。 |
| 回答偏向通用建议、缺项模板和大量诊断 | 产品按现有知识库简短介绍；单候选建议显示真实厚度、K、不同 R 口径及来源。资料缺失或冲突解释具体原因。缺计算绑定时先说明可核验参考，不代填模型或厚度作用层。完整诊断继续保存。 |
| 方案硬条件指纹漏掉部位等字段 | 部位、屋面形式、正倒置、原表编号、型号集合等纳入硬条件变化校验；变化后不能沿用之前的冲突保留确认。 |
| 同路径打开第二份报告仍使用第一份全局路由 query | App 报告详情使用本页面 onLoad 的报告 ID；缺 ID 清理、用户隔离、迟到响应失效与 PDF hash 校验继续保留。真实打开两份报告，核对各自 Snapshot 和全部页面。 |

没有加入针对失败原句的专用正则、虚构型号、工程默认参数或放宽授权。固定 35 问的原文与预期没有修改。

## 真实验收方法

两套设计师/销售原对话各 8 轮，原文冻结。每轮通过 H5 输入并发送，记录原始 SSE、实际 BackendDecision、QueryState、候选、Solution 状态及页面截图。按钮动作单列，不冒称聊天自动执行。确认前不生成 Snapshot；报告使用真实确认后的冻结数据。

原始 35 问共 10 个场景、35 个用户轮次，原文件 SHA256 为 `59f1de38bfb5d48bb9fb4207e4e1b48175342f52b7fe201bc7fcecbe35342857`。执行之后按回答内容、最终条件、返回事实及页面操作判断 PASS / PARTIAL / FAIL，不根据 HTTP 200、模型拒绝或文件存在判断通过。

额外复测用户原四组失败对话、知识库产品连续咨询和换题探索。同一执行者编写/执行的探索不称为独立人工盲测；真正独立人工盲测仍需客户参与。

所有失败轮次保留。源码冻结后复测，另存源码清单与漂移检查。数值核验另用 Decimal 从真实计算记录冻结的各层参数重算，不调用业务热工计算器作为自己的预期。

## 仍存在的资料限制

1. 正式 `VICP-LAYERED` 参考行标注 35mm，但关联 `VICP-BOARD-25` 的规格板厚为 25mm。用户已确认暂无正式修订依据。两处原值和来源均保留、显示为只读冲突，不能据此构成第二套正式候选或放入最终报告。要求同时保留此冲突候选的组合指令不会部分执行。完整双方案验收因此仍受阻。
2. 客户原表 A2-2 的基层/厚度档位以及 A3-3 的 λ 数值存在疑点。用户已确认保留原值、标注疑点；软件不自行勘误，不混用不同来源的工程参数。
3. 当前没有正式标准限值和完整产品用途/组成/优势手册。可以介绍已发布知识库、参数和参考做法；不能给出正式达标结论、编造产品性能或竞品优势。
4. 生产免责声明模板仅准备变更，隔离库已按真实创建新版本、验证、提审、审核、发布流程验证。生产发布仍需使用正式模板版本流程，不能直接改旧模板或旧 Snapshot。
5. 基线自动测试有一项已知口径差异：已发布分层引擎的 `productResistance` 仅汇总 PRODUCT_LAYER，芯材 15mm 的结果为 4.8；甲方 Excel 的复合产品整体 R=5.0 还包含两层包覆浆料。回复已明确标为产品层/芯材范围，不能冒称复合板整体 R。没有为了让测试变绿而改正确预期或已发布规则。如果要正式新增或改变产品整体热阻口径，应先确认产品组/子层归属，派生 VICP-CALC-2；V1 与历史 Snapshot 保持原口径。本地缺少原图集 PDF，相关全文提取回归为条件跳过，原页图片及生成报告另做真实页面验证。
