# C端人工完整流程测试（2026-10-22）

主线使用当前已核验的25mm整体法参考方案，覆盖查询、参数与来源核对、候选恢复、选择、Final、Confirm、Snapshot、PDF生成和预览。本流程参考已通过的真实H5单方案按钮闭环；人工测试仍需记录实际结果，不能保证任意模型输出都必然成功。

这不是双方案比较验收：35mm分层参考行与25mm规格的冲突尚未修订，只能查看两处记录，不能拿来凑第二个正式候选。文件下载本轮跳过。

## 照着执行的主线

在C端登录后新建一个对话，以下步骤保持在同一对话里。

### 1. 查询可用方案

发送：

> 查询已发布的VICP-OVERALL参考行，保留输入条件及来源。

检查：出现25mm参考方案及“加入方案”入口；查询本身不能自动完成选择、确认或生成报告。来源为Sheet1的正式参考记录，不应伪称已有原图。

当前这条发布记录的核对值如下，字段含义按原表保留：

| 核对项 | 当前可信值 |
| --- | --- |
| 构造 | VICP-OVERALL，热阻整体计算 |
| 基层 | 钢筋混凝土，200mm |
| 产品规格/厚度 | VICP-BOARD-25，25mm |
| 产品层热阻R | 4 m²·K/W |
| 总热阻 | 4.3068 m²·K/W |
| K | 0.2322 W/(m²·K) |
| 来源 | VICP热工计算表格公式，Sheet1 |

这些值用于核对当前记录，不表示本次重新计算或地区达标。若后台以后正式修订了记录，应按其当前来源和版本核对，不要求旧值永远不变。

### 2. 检查历史恢复

退出当前页面，再从“历史会话”打开刚才这条对话。

检查：仍能看到同一条候选；不能出现别人的会话、旧编号错配或自动选择。

### 3. 加入方案

点击这条25mm候选的 **“加入方案”**。

检查：出现已选状态，所选仍是VICP-OVERALL / 25mm；尚未确认、尚未生成Snapshot或PDF。

### 4. 设置最终方案

点击 **“选为最终方案”**，在确认界面点击 **“设为最终方案”**。

检查：它成为Final，仍未完成正式确认。本步骤不要混入“保留35mm分层作对比”等复合要求；该参考记录目前有数据冲突。

### 5. 用对话核对Final

发送：

> 核对最终方案的参数、规则版本和Sheet1来源。

检查：答案对应刚才选中的25mm方案，参数与第1步一致，来源及可核验版本按实际记录说明。没有正式公式版本时，应说明它来自已发布参考行，不能编造计算版本或宣称重新计算。此问题本身不能代替确认，也不能生成报告。

### 6. 正式确认并生成快照

点击 **“确认生成方案”**。

检查：界面显示已确认；Final的参数和来源被固定为这次确认的Snapshot。重复点击应复用同一确认结果，不能重复增加快照。

### 7. 生成PDF

点击 **“生成技术方案 PDF”**，等待生成完成后打开报告详情。

检查：报告进入可预览状态；若失败，应显示真实失败原因。只有文件存在或状态为READY还不够，继续下一步核对实际页面。

### 8. 预览并核对报告

点击 **“预览 PDF”**，翻页，放大/缩小；在手机宽度下再查看一次。

检查：报告中的最终方案、25mm厚度、R=4、总热阻4.3068、K=0.2322和Sheet1来源应与本次Snapshot一致；没有进行正式地区标准核验时，不应写成“已达标”“通过审图”或“可施工验收”。报告不能换成别的方案、混入冲突35mm行，或者重新读取后台新参数覆盖快照。

本轮 **不要点击下载**。生产免责声明模板的新版本若尚未发布，出现旧占位文字应单列记录为模板待发布事项，不拿它当本次模型生成成功的证明。

## 主线完成后，另开一个对话测冲突说明

发送：

> 查询已发布的VICP-OVERALL和VICP-LAYERED参考行，分别保留输入条件及来源。

继续发送：

> 比较这两套方案。

检查：能看到35mm参考表原值、25mm关联规格原值、Sheet1和规格各自来源/版本，并用通俗语言说明厚度不一致。有效25mm方案仍可查看；冲突记录只能核对资料，不能变成第二个可确认候选。不能静默改成25mm，也不能假装已比较两套合格方案。

## 发现异常时记录什么

保留原始提问和回答截图、发生时间、会话和报告页面；说明卡在哪一步、点击了哪个按钮。不要通过连续改写同一句或反复点击把一次偶然成功当作通过。

若页面完全没有“加入方案”“选为最终方案”“确认生成方案”或“预览PDF”等入口，先核对C端版本。本次发布仅后端，之前App/H5前端修复不会随后端自动上线；缺少对应前端时，需要同步发布前端，不能靠换提问绕过确认门禁。
