# AI 参考页展示

本次仅扩展 AI 消息的来源数据与已有 `knowledge-source` 页面，不调整 AI 回答生成、人工确认流程和 PDF 阅读。

## 数据与展示

- `reference_pages` 流事件及 `done.referencePages` 进入 assistant store；同一个 documentId/pageId 合并为一页，保留多个命中。
- 同一正式 constructionId/optionId 的最终段落引用接替流式待定位引用，即使 candidateId 或可选 pageId 字段不同，也不会在回答开头额外重复展示；不同段落中的正式引用仍分别保留，fieldKeys 合并。
- 正式 `renderModel` 配合 constructionId/optionId 定位；fieldKeys 控制厚度、产品层热阻、总热阻、传热系数的二级高亮。相同数字不会被一起标亮。
- AI 回答内直接展示完整表格；同页跨段引用只展示一张表格，保留全部构造、厚度档位和正式命中。来源详情负责授权校验、正式页标题与原图续签。独立参考页只展示正式页标题、完整原图和一个“全屏查看”按钮；不展示知识库名、目录、页码、图集号、提取文本或表格切换。
- 点击“查看参考页”传递消息标识和正式来源标识，不把图片地址或完整模型放进路由。参考页的全部入口统一显示完整原图；回答内与快照中的表格能力仍由共享表格查看器负责。
- 回答内的完整来源表格按 Backend `answerOffset` 放到关联段落或列表说明下方。仅 Backend 标记 `answerStyle=THERMAL_SOLUTIONS` 且正式模型可定位的查表摘要可被中文参数说明替换，避免参数写两遍；普通引用、条件说明、结论、失效标识和老消息保留原正文。不根据正文中的构造编号或数值猜测匹配。
- 面向销售和设计院，系统名称做主标题，表名括号小字展示；仅对 Backend 页面标题做视觉分层，或使用明确统一的系统名称，不解析 AI 正文。参数使用“保温厚度”“传热系数”等中文说明。回答内去掉匹配数量、当前引用、导航和高亮开关；只保留同一行等宽的描边“查看参考页”和实底“全屏看表格”，表格命中仍突出。默认展示后端顺序的前两页，其余可展开，不在前端排序或推荐最优。资料名称、图集号与印刷页码置于表格底部引用区域。
- 编号格的构造编号与系统名称相同时只显示一次；不同的正式系统名称仍可保留，不改 Backend 原数据或定位标识。
- 回答内与快照中的共享表格复用 B 端投影方式，整页共用表头，同页各构造分组保留公共层和全部档位。仅 Backend 明确标记的唯一可变层嵌入 options；无关联或多个可变层时另列档位，不猜关联。编号、材料、公共 λ/α 合并，外墙主断面 R₀/K 保持连续列，按正式标识高亮。表头与表体同步横向滚动，长表内部纵向滚动时表头保持可见。构造简图由独立参考页的完整原图提供。
- 数值直接展示 Backend 值；数值型 R/R₀/K 补足三位小数，但不截断额外精度；字符串保留 Backend 格式。不从回答抽取数值，不计算 K，不修正识别结果。
- 独立参考页先通过 uni.getImageInfo 读取图片，使用返回的临时路径按 widthFix 原比例完整展示，去掉固定 900rpx 图片占位；点击原图或唯一的全屏按钮使用 uni.previewImage 预览。加载中显示进度，加载失败/无图通过 wd-empty 提供重试和可用原文件入口；双指缩放依赖运行平台能力，需在小程序/App 真机复核。
- 旧消息缺少 renderModel 时显示完整原页，图片缺失或失效时提供参考页入口重新获取；缺少正式行标识时不伪造高亮。

## 网络与存储

2026-10-12 修正参考页入口传参：当前安装的 `@wot-ui/router` 在 `name` 命名跳转中只序列化 `params`，不会读取 `query`。此前三个入口丢失 documentId/pageId 等参数，页面在来源定位校验时直接失败，没有触发详情接口。三个入口统一通过 `knowledgeSourceLocation` 使用 `params`，回归使用实际安装的路由库核对 URL 中的来源、原文件和命中参数。页面异常与无内容状态采用 Wot `wd-empty`，重试/原文件操作放入 `bottom` 插槽。

2026-10-12 图片排查：只读核对截图的“测试知识库”第41页，正式原图存在，PNG为2723×1956、442025字节，HTTP及同一签名HTTPS的GET均返回200，图像可解码且不是空白页。Backend当前返回HTTP OSS签名；图片读取时仅将已验证的阿里云OSS域名升级HTTPS，原样保留签名/过期查询参数，其他域名不改协议。原生读取、迟到请求取消和HTTPS签名保留均有回归覆盖。未修改线上数据或后端部署。

沿用 `/ai/knowledge/source-detail` 和现有 Alova 网络层。进入来源页重新请求详情，核对 documentId/pageId；加载失败提供重试。图片失败仅自动重新获取详情一次，再失败由用户手动重试，避免循环请求。离开页面忽略迟到响应。

签名图片地址只在内存使用，assistant 本地存储写入及恢复时清除 referencePages 的旧地址。前端沿用现有接口与依赖。

## Backend 接入（2026-10-11）

Backend 已补充来源详情 `page.renderModel`；正式热工候选与同页同构造四项一致的确认档位唯一绑定，返回 constructionId/optionId/fieldKeys。知识回退在已选当前发布资料确认快照中匹配，查表正文与页面数值同源，并返回 answerOffset。确认数据冲突时不猜高亮。

会话历史已返回 referencePages，并在会话归属校验后重新检查来源发布状态、项目范围及确认快照ID，再签名原图。消息元数据只存来源标识/objectKey/快照，不存临时URL；撤回、换版或失效ID会返回空数组，前端不会复活本地旧缓存。

对当前设备已接收的来源，重新加载会话时仅在消息 ID、会话 ID、完整正文均未改变，且服务器没有明确返回来源字段时保留本地来源，清除旧签名图片地址。跨设备历史仍需要 Backend 返回 referencePages。

B 端当前版本知识测试与 C 端生产对话的检索入口不同：前者限定知识版本，后者检索已发布资料并由 Agent 工具生成回答。不能要求前端将两者返回值强行改成一致。回答中的逻辑矛盾应由 Backend 的检索、事实绑定与回答生成链路修正。

后端改动与回归说明见[后端完整参考页说明](../../backend/docs/ai/c-reference-pages.md)。真实HTTP/SSE UAT已尝试，但数据库连接ECONNREFUSED，123轮均BLOCKED、执行0轮。需恢复依赖后完成正式发布资料的线上联调，不能以协议夹具或搜索答案数字替代。
